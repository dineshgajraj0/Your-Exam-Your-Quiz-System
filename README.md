# Your Exam Your Quiz System

A simple console-based Quiz System developed in C programming language.

## 📚 Subjects

- Math
- Science
- History
- Coding

## ✨ Features

- Multiple-choice questions
- 4 options for every question
- Automatic score calculation
- Shows the correct answer for wrong answers
- Subject-wise question files
- Final quiz result
- Simple and easy-to-use interface

## 🛠️ Technologies Used

- C Programming
- Structures
- Functions
- Arrays
- File Handling
- Standard C Libraries
